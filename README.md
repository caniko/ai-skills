# caniko's AI Skills Mirror

Checked-in mirror of caniko's global and project-local AI agent skills.

This repository is data, catalog output, and configuration. The CLI that
reconciles the mirror lives in the separate
[`skillnet`](https://codeberg.org/caniko/skillnet) project.

## Layout

```text
global/
  <skill-name>/              # reconciled global skills

projects/
  <project-name>/
    <skill-name>/            # reconciled project skills
    INDEX.md                 # generated project skill index
```

Top-level generated catalog files:

- `CATALOG.md`
- `ROUTING.md`
- `SKILL_CONFLICTS.md`

Configuration:

- `skillnet.toml` declares live sources, sync targets, and project roots.
- `skillnet.catalog.toml` declares catalog metadata and taxonomy rules.

## Usage

Inspect the mirror:

```sh
skillnet --config ./skillnet.toml --catalog-config ./skillnet.catalog.toml status
```

Pull live skill sources into the checked-in mirror:

```sh
skillnet --config ./skillnet.toml --catalog-config ./skillnet.catalog.toml --allow-dirty-destination sync pull --all
```

Regenerate catalog output:

```sh
skillnet --config ./skillnet.toml --catalog-config ./skillnet.catalog.toml --allow-dirty-destination catalog generate
```

Push the checked-in mirror back to live `.agents/skills` and `.claude/skills`
targets:

```sh
skillnet --config ./skillnet.toml --catalog-config ./skillnet.catalog.toml sync push --all
```

The wrapper script runs the normal pull-and-sync workflow:

```sh
scripts/reconcile-skills.nu
```

`skillnet` guards mirror writes when this Git working tree is dirty. During an
intentional cleanup or regeneration pass, use `--allow-dirty-destination`.

## Notes

- `global/` and `projects/<project>/` are generated by `skillnet`.
- `skillnet sync pull` reads all configured live sources, including global
  `.agents`, `.claude`, `.codex`, project skill directories, plugin skill
  directories, and configured project extras.
- `skillnet sync push` writes selected mirror skills back to live `.agents` and
  `.claude` directories and removes stale `.codex/skills` copies.
- `skillnet catalog generate` rebuilds catalog docs and project indexes.
